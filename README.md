# Groovy-game
game for groovy

## Leafy Manor entrance hall

Everything for the Leafy Manor hall is in [`LeafyManor/`](LeafyManor/README.md):
- **Unreal:** run `LeafyManor/Unreal/Python/leafy_manor_build.py` in the editor to build the level.
- **Browser game:** run `cd LeafyManor/Web && python3 -m http.server 8000`, then open http://localhost:8000.
