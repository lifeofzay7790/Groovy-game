# Groovy-game
game for groovy

## Leafy Manor entrance hall

Everything for the Leafy Manor hall is in [`LeafyManor/`](LeafyManor/README.md):
- **Unreal:** double-click `Build Leafy Manor.bat` to build the level, then `Play Leafy Manor.bat` to play it (Windows). Or run `LeafyManor/Unreal/Python/leafy_manor_build.py` in the editor yourself.
- **inside the copy of the zip folder**
- **Browser game:** run `cd LeafyManor/Web && python3 -m http.server 8000`
- **Browser game:** run 'cd LeafyManor/Web python -m http.server 8000', then open http://localhost:8000.
